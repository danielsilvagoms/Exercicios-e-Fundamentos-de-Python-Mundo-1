# 🐍 Python 3 - Mundo 1: Fundamentos

Repositório criado para armazenar os exercícios e desafios concluídos durante o **Mundo 1 do curso de Python 3** do Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

O objetivo desta etapa foi consolidar a base da linguagem Python e o raciocínio lógico.

---

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python 3
* **IDE:** VS Code / PyCharm
* **Versionamento:** Git e GitHub

---

## 📚 Conteúdos Abordados

* **Módulo 1:** Primeiros passos, instalação e comandos básicos (`print`, `input`)
* **Módulo 2:** Tratamento de dados e operações aritméticas (`int`, `float`, `str`, `bool`)
* **Módulo 3:** Utilização de módulos e bibliotecas padrão (`math`, `random`, `pygame`)
* **Módulo 4:** Manipulação de texto (fatiamento, análise e transformação de *strings*)
* **Módulo 5:** Estruturas condicionais simples e compostas (`if` / `else`)
